- **3D Interactive Character & Canvas**: Real-time rendering with Three.js, Draco compression, and dynamic camera movements.

- **Introduction Screen**: Interactive loading capsule with real-time percentage indicator and fluid entry sequence.

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Shafiq-456/Mohammed-Shafiq-Portfolio.git
   cd Mohammed-Shafiq-Portfolio
   ```

2. Start a local HTTP server:
   ```bash
   # Using Python 3
   python3 -m http.server 8090

   # Or using Node http-server / npx serve
   npx serve .
   ```

3. Open `http://localhost:8090` in your web browser.
