## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Shafiq-456/REPOSITORY-NAME.git
```

**2. Navigate to the project directory**

```bash
cd REPOSITORY-NAME
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

*Note: These commands assume the project exposes the corresponding npm scripts. Check package.json if your scripts differ.*
